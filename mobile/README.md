# Приложение «Дистрибуция»

Одно приложение для торгового агента и экспедитора (Flutter, Android): после входа экран зависит от
роли — у агента «Мой день», у экспедитора «Рейс». Директор, оператор и кладовщик работают в веб-админке,
в приложение они не входят. Сервер — этот же проект, адреса `/api/mobile`.

**Сейчас:** вход и выход, смена временного пароля; «Начать день» / «Закончить день» и GPS; у агента «Мой
день» — маршруты по дням недели, магазины по порядку обхода с долгом, просрочкой и отметкой визита,
карточка магазина с визитом; новый магазин с телефона; карта магазинов. У экспедитора пока только рабочий день.

Визит: в карточке магазина «Начать визит» — только в открытый рабочий день, отметка там, где агент. Дальше
радиуса из настроек компании (обычно 200 м; точность GPS засчитывается в пользу агента, но не больше 50 м) —
только подтвердив: на «Карте» в админке такой визит помечен «далеко». У магазина нет точки на карте —
расстояние не считается. Пока визит идёт — «Фото полки» (камера, JPEG до 1600 px;
обязательно, если так в настройках), «Заказ», «Без заказа» с причиной (частые — одним касанием, или своя),
«Отменить визит» (стирается, на сервер не уходит). Законченный визит пишется на телефон и уходит на сервер,
фото — следом. Визиты и заказы за сегодня с сервера показываются вместе с телефонными.

Заказ: товары по категориям с поиском (название или штрихкод), количество кнопками или числом («+ коробка»),
цены по прайсу магазина на день синхронизации; товар без цены не добавить. Выбранное сразу пишется
черновиком — приложение закрылось посреди заказа, товары на месте. «Оформить» — оплата (наличные; Kaspi и в
долг — если разрешены в настройках), дата доставки (по умолчанию через дни из настроек, не дальше 14 дней),
комментарий; в долг сверх лимита — предупреждение, что заказ уйдёт на разрешение. Сохранённый заказ
заканчивает визит; после отправки в карточке магазина — номер, итог и статус сервера (цены окончательно
считает сервер), в т. ч. «Нужно разрешение» и отмена с причиной после обновления данных.

Новый магазин: на «Мой день» кнопка «Магазин» — название и телефон обязательны, адрес или ориентир (в селе
вместо адреса), владелец, ИП/ТОО, БИН (12 цифр), второй телефон, прайс «Опт»/«Розница», маршрут (по
умолчанию первый маршрут выбранного дня), точка на карте — где стоит агент, GPS сразу при открытии формы
(«Ещё раз» — снова), и фото фасада. Сохраняется на телефон и уходит на сервер; пока не ушёл — в списке
«Новые магазины» на «Мой день». Сервер ставит его «на проверке» в конец маршрута с лимитом долга из настроек
компании, приложение само обновляет данные, и магазин в маршруте — в нём уже можно работать, оператор
проверяет в админке (там же фото фасада).

Карта (значок в шапке «Мой день»): по умолчанию точки всех магазинов компании — свои (красные — сегодня по
маршруту, зелёные — уже был, тёмные — остальные свои) и других торговых (серые: только название, адрес и
филиал, без долгов). Сверху — филиал и «Все / Мои»; свой магазин открывается на карточку. «Где я» — синяя
точка. Подложка — OpenStreetMap (`flutter_map`), без интернета точки всё равно видны; бесплатные серверы OSM
годятся для небольшого числа агентов, при росте — свой поставщик карт.

Отправка (`outbox.dart`): журнал, точки GPS, новые магазины, визиты, фото и заказы уходят одной очередью,
когда есть сеть (новый магазин раньше визитов, визит раньше своего заказа); повтор не задваивает. Нет сети — приложение само повторяет раз в минуту, пока
есть что отправить, и при возврате в приложение. Визит, заказ или магазин, который сервер не принял (неверные
данные), помечается и больше не отправляется — видно почему. Меню → «Отправка»: что
ждёт (журнал и GPS, новые магазины, визиты, фото, заказы), когда последний раз всё ушло и почему не уходит, «Отправить
сейчас»; не принятое сервером — с причиной, его можно убрать с телефона.

Рабочий день: «Начать день» спрашивает доступ к местоположению (без него день не начинается) и запускает
фоновую службу с уведомлением «Рабочий день идёт» — точка GPS раз в интервал из настроек компании (обычно
5 минут), и при погашенном экране. «Закончить день» и выход из приложения её останавливают. Журнал — открыл
приложение, начал и закончил день, выключил и включил GPS — и точки сначала пишутся на телефон (SQLite),
потом уходят на сервер пачкой (`POST /api/mobile/track`); без сети копятся, сколько ждёт отправки, видно
на карточке дня. Открытый сегодня день переживает перезапуск приложения, вчерашний не продолжается.
На Android 13+ уведомление службы видно, только если приложению разрешены уведомления.

Данные агента (настройки, товары и цены, маршруты, магазины с долгами) хранятся на телефоне в SQLite и
обновляются с сервера при открытии и потягиванием экрана вниз. Без сети видно то, что на телефоне, и когда
это обновляли. При выходе данные с телефона стираются.

Вход как в CRM: пароль вводится на телефоне один раз — сервер выдаёт JWT на 12 часов и ключ устройства.
Ключ хранится в защищённом хранилище Android; JWT истёк или сервер перезапускался — приложение само берёт
новый по ключу. Сервер закрыл вход (выход, сброс пароля, отключение) — приложение возвращается на вход с
подсказкой. Без сети приложение открывается с тем, что на телефоне. Резервная копия в облако Google
отключена: вход не переезжает на другой телефон.

## Сборка и запуск

Нужны Flutter 3.47+ и Android SDK (JDK 17).

```bash
cd mobile
flutter test                      # тесты
flutter build apk --debug         # build/app/outputs/flutter-apk/app-debug.apk
```

Телефон с сервером на этом компьютере: включить отладку по USB, затем

```bash
adb reverse tcp:8090 tcp:8090     # localhost:8090 телефона → сервер на компьютере
adb install -r build/app/outputs/flutter-apk/app-debug.apk
```

Адрес сервера по умолчанию — `http://localhost:8090`; для боевой сборки задаётся при сборке
(`--dart-define=API_URL=https://…`) и меняется на экране входа («Сервер: …»). Без шифрования приложение
ходит только на `localhost` и эмулятор (`10.0.2.2`), остальное — только `https`.

## Устройство

```
lib/
  main.dart           вход или главный экран — по тому, кто вошёл
  theme.dart          цвета как у веб-админки (шоколад, пергамент, малиновый)
  session.dart        кто вошёл, ключ устройства (защищённое хранилище) и адрес сервера
  device.dart         модель телефона и версия приложения — для журнала входов на сервере
  format.dart         деньги, даты, склонения
  workday.dart        рабочий день: начать/закончить, GPS раз в интервал, журнал
  visits.dart         визиты и заказы дня: начать по GPS, фото полки, заказ, без заказа, отменить, черновик
  outbox.dart         очередь отправки на сервер: журнал, точки, новые магазины, визиты, фото, заказы
  location.dart       GPS (фоновая служба с уведомлением, отметка в магазине) и заряд батареи
  camera.dart         камера для фото полки и фасада, папка фото до отправки
  geo.dart            расстояние между точками
  api/api_client.dart запросы к /api/mobile: JWT, продление по ключу, понятные тексты ошибок
  data/               данные агента, журнал, точки GPS, визиты, заказы, новые магазины — база SQLite на телефоне
  screens/            вход, свой пароль, «Мой день» агента, карта, карточка магазина, заказ, новый магазин,
                      «Отправка», экспедитор
  widgets/            общие кусочки экранов (карточка рабочего дня, визит, сообщения)
```
