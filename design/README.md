# Макеты

Дизайн Дистрибуции и её связи с CRM. По этим макетам делаются приложения и админки — это не код.

Холст с кликабельными экранами: https://claude.ai/artifact/YYEbUUnhNGhRMPohDNw5Eu (открывается
под аккаунтом владельца).

| Папка | Что внутри |
|---|---|
| `mobile/` | приложения экспедитора и торгового представителя, Telegram-бот |
| `admin/` | админка Дистрибуции |
| `crm/` | что добавляется в админку CRM для связи с Дистрибуцией |

`canvas.json` — раскладка всего холста: страницы, положение и названия экранов. Файлы `*.dc.html` —
исходники холста: в обычном браузере они не открываются, им нужен движок холста.

Суммы, сроки, имена и пороги в макетах — примеры.
