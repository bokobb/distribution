# Макеты мобильных приложений

Макеты приложений экспедитора и торгового представителя, а также Telegram-бота для руководителя
и магазинов. Это дизайн, по которому делается приложение на Flutter, а не код приложения.

Холст с кликабельными экранами: https://claude.ai/artifact/YYEbUUnhNGhRMPohDNw5Eu (открывается
под аккаунтом владельца).

## Что в папке

- `*.dc.html` — экраны 390 × 844, по одному на файл. Это исходники холста: в обычном браузере они
  не открываются, им нужен движок холста.
- `canvas.json` — раскладка холста: страницы, положение и названия экранов.
- `assets/` — карты для экранов маршрута. В файлах экранов они подключены как картинки,
  загруженные на холст:
  - `/_blob/a31fa0c9a72c7a9f07a3e5b7d9375443` → `assets/map-expeditor.svg`
  - `/_blob/752a50f4e0517dba7c76b70bfa64b913` → `assets/map-agent.svg`

## Что заложено в макетах

Суммы, сроки и пороги в макетах — примеры.

- У заказа в приложениях два статуса: «Новый», после доставки — «Доставлен».
- Доставка закрывается только с подписью получателя на экране или с фото накладной.
- Старый долг принимается в карточке доставки отдельной суммой и попадает в наличные на руках.
- При сдаче кассы экспедитор считает купюры, приложение сверяет итог с суммой к сдаче.
- Заказ магазину закрывается сам при большой просрочке (в макете — больше 14 дней или
  больше 30 000 ₸). Руководитель может разрешить один заказ прямо в Telegram.
- Магазин может заказать сам через бота: повторить прошлый заказ или собрать его в каталоге.

## Дизайн-токены

Шрифт — Inter (400, 500, 600, 700). Суммы набираются моноширинными цифрами (`tabular-nums`).

| Назначение | Цвет |
|---|---|
| Акцент: кнопки, маршрут | `#4136F1` |
| Нажатие, ссылки | `#3329D6` |
| Подложка акцента | `#EEEDFE` |
| Текст | `#101318` |
| Второй текст: подписи, адреса | `#5C6370` |
| Значки | `#8C929C` |
| Линии | `#E8EAEE` |
| Заливка вторых кнопок | `#F1F2F5` |
| Фон экрана / карточки | `#F4F5F7` / `#FFFFFF` |
| Успех: доставлено, сумма сходится | `#12805C`, фон `#E7F5EF` |
| Внимание: частично, долг | `#9A5B00`, фон `#FFF4DF` |
| Ошибка: отказ, больше суммы | `#C4291C`, фон `#FDECEA` |

Экран 390 × 844, поля 16, цель касания не меньше 44. Скругления: карточки 16–20, кнопки 14,
поля ввода 12–14. Шрифт: 28/34 — заголовок экрана, 22/28 — суммы, 18/24 — заголовок карточки,
16/22 — кнопки, 15/21 — основной текст, 13/18 — подписи, 11/14 — нижнее меню.
