# Дистрибуция

Система для компаний, которые развозят продукцию по магазинам: торговые агенты собирают заказы,
склад грузит машины, экспедиторы доставляют, берут оплату и забирают негодный товар.

Одна система обслуживает несколько компаний: собственную доставку производства и склады-дилеры
со своими директорами и командами. Данные каждой компании отделены. Владелец видит все компании,
а сводка выводится на главном экране CRM производства (`bokobb/CRM`).

## Что сейчас в репозитории

**Этап «шаблоны админки».** Готова веб-админка на данных-заглушках (`stub/StubStore`):

| Раздел | Адрес | Что на странице |
|---|---|---|
| Дашборд | `/admin/dashboard` | выдано сегодня, заказы на завтра, наличные на руках, долги, возвраты; по компаниям; агенты; рейсы; «требует внимания» |
| Заказы | `/admin/orders` | на завтра / сегодня, фильтр по статусу, поиск; карточка заказа с историей; разрешение заказа сверх лимита долга; отмена; лист сборки |
| Магазины | `/admin/outlets` | список с долгом и лимитом, карточка, форма, проверка новых магазинов от агентов |
| Долги магазинов | `/admin/debts` | долги, просрочка, сверх лимита |
| Маршруты и регионы | `/admin/routes` | регионы → маршруты (агент, дни) → магазины |
| Рейсы | `/admin/trips` | рейсы дня, точки по порядку, загрузка машины |
| Приём кассы | `/admin/cash` | наличные на руках, приём рейса: пересчёт, Kaspi, товар, недостача |
| Склад и приходы | `/admin/stock` | остатки (резерв, в машинах, негодный), приходы, автоприход из CRM |
| Товары и прайс | `/admin/products` | каталог компании, опт/розница, код товара CRM |
| Сотрудники и машины | `/admin/staff` | роли, связь телефонов агентов и экспедиторов, машины |
| Отчёты | `/admin/reports` | «Качество: что возвращают магазины» и заготовки остальных |
| Импорт из Doctor Sales | `/admin/import` | мастер: файл → проверка колонок → итог (пока пример) |
| Компании | `/admin/companies` | только владелец: компании, их директора, клиент в CRM |
| Настройки | `/admin/settings` | визиты, долги, касса, связь с CRM |

Вход ещё не подключён. В меню пользователя (справа вверху) есть «Смотреть как»: так можно
проверить, что видит владелец, директор, оператор и кладовщик. Владелец переключает компанию
в шапке или смотрит «Все компании».

Заглушки пересоздаются при каждом запуске. Цифры случайные, но связанные между собой: рейс
состоит из заказов, касса — из оплат по точкам. Поэтому сводки на разных страницах сходятся.
Действия (разрешить заказ, принять кассу, принять приход, проверить магазин) меняют данные в
памяти до перезапуска. Формы магазина, компании и настроек пока ничего не сохраняют.

## Запуск

```bash
./gradlew bootRun
# http://localhost:8090/admin
```

Нужна Java 17+. Базы пока нет.

## Устройство

```
src/main/java/com/confectionery/distribution/
  domain/   сущности и статусы (пока обычные классы, на этапе 1 станут JPA)
  stub/     StubStore — все данные в памяти (заменяется репозиториями на этапе 1)
  admin/    контроллеры страниц, меню по ролям (AdminSections), компания и роль (AdminContext),
            форматирование для шаблонов (Fmt → ${@fmt.money(x)})
src/main/resources/
  templates/admin/   Thymeleaf-шаблоны, общий каркас — layout.html
  static/admin/assets/  admin.css (палитра админки CRM), admin.js
  admin/icons.json   значки, как в CRM
```
